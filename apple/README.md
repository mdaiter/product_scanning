# apple/

Swift side of shelfscan. Builds and tests on macOS 26 / Xcode 26 (2026-10-25): `bash scripts/swift_test.sh`.
The Vision and Capture sources compile; what they do is tested in `Tests/ShelfScanTests` (Phase 1.3) and the demo app (1.4).
The iOS build has not been tried yet (the iOS platform is not installed in Xcode on the dev Mac).

```
scripts/build_xcframework.sh   -> apple/build/shelfscanFFI.xcframework + apple/Sources/ShelfScan/shelfscan.swift
Sources/ShelfScan/             generated UniFFI Swift (git-ignored, regenerated by the script)
Sources/ShelfScanVision/       Vision plugins: barcode scanner, feature-print embedder, foreground-instance detector
Sources/ShelfScanCapture/      AVFoundation CameraSource, ScanModel (events -> SwiftUI), OverlayView
Tests/ShelfScanTests/          XCTest; reads PNG fixtures from Tests/ShelfScanTests/Fixtures (git-ignored, `shelfscan fixtures`)
```

See `docs/phase-1-mac.md` and `docs/phase-2-iphone.md` for what to build and how it is accepted.
